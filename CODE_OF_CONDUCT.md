# Code of conduct

This project follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Please report unacceptable behavior privately to the maintainers through a
[GitHub security advisory](https://github.com/itlinuxfr/oc-precheck/security/advisories/new)
or to the e-mail address listed on the maintainer's GitHub profile.
